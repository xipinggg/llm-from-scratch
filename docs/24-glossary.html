术语表

数学与基础

术语一句话
张量（tensor）多维数组；本页模型里一个 token 是 8 维向量，一批是 [T, 8] 的矩阵。
点积逐元素相乘再相加，衡量两个向量的"同向程度"，注意力打分的核心。
softmax把任意实数变成非负、和为 1 的分布；带温度参数。
交叉熵预测分布与真实标签之间的损失，语言模型预训练的目标。
困惑度（PPL）交叉熵取指数，可理解为"每一步在多少个候选里犹豫"。
梯度下降沿损失对参数的负梯度方向更新参数；学习率决定步长。
链式法则复合函数求导的分解规则，反向传播的全部数学基础。
反向传播从损失往回逐层计算梯度；手写实现见第 19 章。
Adam / AdamW按梯度的一阶与二阶矩自适应调整步长的优化器。
数值梯度校验用微小扰动近似导数，与解析梯度对比，验证反向传播写对没写对。

分词与嵌入

术语一句话
token模型处理的最小单位，可以是字符、子词或字节。
词表（vocab）所有 token 的编号集合，决定模型的输入输出空间。
BPE从字符出发，反复合并最高频的相邻对，得到子词词表。
字节级 BPE以 UTF-8 字节为起点，任何文本都不会出现未登录词。
嵌入（embedding）把 token 编号查表变成向量；可训练的参数矩阵。
位置编码让模型知道 token 顺序的信息，本页用可学习绝对位置，主流用 RoPE。
RoPE旋转位置编码，把位置写成向量的旋转，点积中自然出现相对位置。
权重共享（tied）输入嵌入表与输出投影共用同一矩阵，省一半词表参数。

注意力与结构

术语一句话
Q / K / V查询、键、值：同一个输入向量乘三个矩阵得到的三种角色。
因果掩码让位置 i 只能看见 ≤ i 的位置，保证训练与生成一致。
多头注意力把向量切成若干头，各自独立做注意力，再拼回投影。
MHA / MQA / GQA头与 KV 的共享程度：每头独立 / 全部共享 / 分组共享。
MLA把 KV 缓存成低维隐向量，用时再投影，DeepSeek 的方案。
残差连接输出 = 输入 + 子层输出，给梯度留一条恒等通路。
LayerNorm / RMSNorm按特征维做归一化；RMSNorm 只除均方根，更快。
Pre-LN / Post-LN归一化放在子层之前还是之后；前者更容易训练深层。
FFN两层线性加一个非线性，占 Transformer 参数的大头。
SwiGLU带门控的前馈结构：升维后一分为二，一份做门。
MoE多个专家 FFN，每个 token 只激活其中几个，总参数与计算解耦。
路由（router）决定一个 token 该走哪几个专家的打分网络。
负载均衡损失防止所有 token 挤向同一专家的辅助损失。
QK-norm对 Q/K 做归一化，抑制长训练中注意力分数的爆炸。

训练与对齐

术语一句话
预训练在海量文本上做下一个 token 预测，得到基座模型。
缩放定律损失随参数量、数据量、算力呈幂律下降；Chinchilla 给出 20 token/参数的配比。
SFT监督微调：用指令-回答对训练，只对回答部分算损失。
RLHF用人类偏好训奖励模型，再用 RL 优化策略。
DPO跳过奖励模型，直接在偏好对上优化策略。
RLVR用可自动验证的奖励（答案对错）做强化学习。
PPO / GRPO带裁剪的策略梯度；GRPO 用组内均值当基线，省掉价值网络。
奖励黑客策略钻奖励模型的空子，指标好看但行为变坏。
能力涌现规模跨过某个阈值后评测分数突然抬升的现象。
对齐税对齐训练后某些基础能力反而下降的代价。
DP / TP / PP / EP数据、张量、流水线、专家并行，四种切分方式。
ZeRO / FSDP把优化器状态、梯度、参数分片，省显存。

推理与服务

术语一句话
prefill把整段输入一次算完，计算密集。
decode每次只生成一个 token，带宽密集。
KV cache缓存历史 token 的 K/V，避免重复计算；显存随上下文线性增长。
TTFT / TPOT首 token 延迟 / 每 token 间隔，两个用户可感知的指标。
MHA 的 KV 公式每 token 2·L·H_kv·d·b 字节，两个 2 分别来自 K/V 与 fp16。
分页注意力把 KV 按块管理，消除预分配的内部碎片，支持共享。
前缀缓存相同前缀的 KV 只算一次，后续请求直接复用。
抢占（preemption）显存不够时丢弃某些请求的 KV，稍后重算或换出。
chunked prefill把长 prefill 切块，与 decode 混批，稳住 ITL。
投机解码草稿模型先猜若干 token，大模型一次验证；用拒绝采样保证分布不变。
约束解码按语法掩掉非法 token，保证输出符合 JSON/正则。
温度 / top-k / top-p调整采样分布的形状与候选池。
beam search同时保留 k 条候选序列，逐 token 扩展取最优。

硬件与性能

术语一句话
算术强度每搬一字节数据做了多少次浮点运算；与脊点比较判断瓶颈。
roofline用"带宽上限"和"算力上限"两条线描述一个算子能跑多快。
Tensor CoreGPU 上专门做矩阵乘的单元，fp16/fp8 吞吐远高于普通核心。
SM流式多处理器，GPU 的调度与执行单元。
显存带宽H100 约 3.35 TB/s，decode 速度的上限由它决定。
kernel在 GPU 上执行的一个函数；一次 decode 有几百个。
流（stream）GPU 上的命令队列，同一流内顺序执行。
CUDA graph把一串 kernel 启动录下来，一次回放，消除 CPU 提交开销。
pinned memory锁页内存，可被 GPU 直接读取，H2D 拷贝更快。
FlashAttention分块计算注意力，不落盘完整的 T×T 矩阵，省显存且更快。
all-reduce多卡之间求和同步，张量并行每层都要做。
NCCLNVIDIA 的集合通信库。
Marlin4bit 权重的 GEMM kernel，在计算时边取边还原。
量化粒度per-tensor / per-channel / per-group，越细误差越小、开销越大。
FP8 e4m38 位浮点，范围约 ±448，H100 原生支持。

长上下文与新架构

术语一句话
位置插值（PI）把位置整体除以倍数，映射回训练见过的区间。
NTK-aware改 RoPE 底数，按维度重新分配频率。
YaRNNTK + 分维度处理 + 注意力温度，少量微调即可长上下文。
滑窗注意力每个 token 只看最近 w 个位置，计算量降到 O(T·w)。
attention sink序列开头几个 token 的 KV 特别大，模型把它们当"落点"。
H2O只保留注意力权重高的 KV，按重要性淘汰。
Mamba / SSM用固定大小的状态递推代替注意力，开销与长度无关。
MTP多 token 预测：一次前向同时预测后面几个位置。
Needle in a Haystack长文本里藏一句话再问，测长上下文的实际可用性。
Lost in the Middle关键信息位于文本中部时更容易被忽略的现象。

推理模型、agent 与 harness

术语一句话
思维链（CoT）让模型先写出推导过程再给答案，用 token 换计算深度。
自一致性采样多条推理链，对最终答案投票。
pass@kk 次采样中至少有一次正确的概率。
PRM / ORM过程奖励模型 / 结果奖励模型。
测试时计算推理阶段多花算力换准确率：更长、更多条、或搜索。
MCTS蒙特卡洛树搜索，用 UCT 平衡探索与利用。
蒸馏用强模型的输出训练小模型。
agent模型 + 工具 + 循环 + 环境 + 预算，能多步完成任务的系统。
工具调用模型输出结构化的调用请求，由 harness 执行并回填结果。
harness模型外面那一圈工程代码：循环、工具、权限、压缩、观测。
上下文压缩把消耗过的工具输出从后续上下文里删掉或摘要，控制 token 增长。
子代理父代理派生子代理执行子任务，只回传结论，隔离噪声。
golden tasks一小批固定的代表性任务，用来做回归测试。

怎么用这张表

术语只是索引。真正要带走的是每个词背后的一两个数字与一条公式——KV 是 2·L·H_kv·d·b，prefill 是计算密集、decode 是带宽密集，投机解码的收益是 (1−α^{γ+1})/((1−α)(1+γc))。记住这些，词自然就记住了。
