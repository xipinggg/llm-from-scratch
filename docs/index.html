大模型是怎么想出一个字的

一份从零讲到大模型完整推理过程的单文件教程的 Markdown 版。所有“逐层演算”的数字都来自本地真实训练的小模型（2 层、宽度 8、1608 个参数），固定种子可复现；示意图与交互演示只存在于 HTML 版。

完整版是仓库根目录的 index.html（离线单文件，含 10 个可交互演示）。本目录是方便阅读、检索与引用而生成的纯文本版。
