第二章 · 数学地基

必备数学：只有六件事

大模型用到的数学，剥掉包装之后只剩六件：向量、点积、矩阵乘法、softmax、交叉熵、梯度下降。这一章把六件事各讲一遍，每个都给具体数字。你不需要会证明，只需要会算和会看形状。

向量：一串有方向的数

一个 8 维向量就是一列 8 个数。在语言模型里，一个 token 的"含义"就是一个向量——不是比喻，是字面意思：模型内部所有关于这个词的信息，都编码在这 8 个数里。

例：字符 m 在位置 19 的输入向量

项值
向量 [8][-1.5651, 0.8432, 0.6085, -0.8543, 0.5743, 0.6986, 1.0881, -0.2305]
怎么来的wte[10] + wpe[19]（字符嵌入 + 位置嵌入，逐元素相加）

点积：衡量两个向量有多"同向"

两个等长向量逐元素相乘再相加：

a⋅b=i=1∑d​ai​bi​=a1​b1​+a2​b2​+⋯+ad​bd​(2.1)

拿两个 3 维的例子手算：a=[1,2,3]，b=[4,5,6]，点积 =1⋅4+2⋅5+3⋅6=4+10+18=32。

点积的几何含义是 a⋅b=∥a∥∥b∥cosθ。两个向量方向越一致，点积越大；垂直时为 0；方向相反时为负。这就是注意力机制的全部秘密：一个位置"想知道"什么（查询 q），和另一个位置"能提供"什么（键 k）做点积，点积大就说明它们匹配，于是把那个位置的内容（值 v）多取一点过来。

为什么是点积而不是别的

因为点积是唯一同时满足"双线性"（对两个输入都线性）和"旋转不变"的简单运算，而且它能写成一次矩阵乘法 QK⊤——这让 GPU 能把成千上万个匹配计算并行做掉。换成"欧氏距离"在数学上也行，但要多算一次平方，且不能直接写成一次矩阵乘。

矩阵乘法：模型 95% 的计算量

矩阵乘向量 y=Wx：W 的第 i 行与 x 做点积，得到 yi​。所以 [m, n] 的矩阵乘 [n] 的向量，得到 [m] 的向量。

例：2×3 矩阵乘 3 维向量

项值
W[[1, 0, −2],<br>[0.5, 2, 1]] 形状 [2, 3]
x[3, −1, 4] 形状 [3]
y = Wx[1·3 + 0·(−1) + (−2)·4, 0.5·3 + 2·(−1) + 1·4] = [−5, 3.5] 形状 [2]

批量版本：X 是 [T, n]（T 个位置，每个 n 维），则 XW⊤ 是 [T, m]。写成 X @ W.T。记忆口诀：中间维度必须对上，结果形状是"两头"：[20,8] × [8,8] → [20,8]；[20,8] × [8,16] → [20,16]。

一次矩阵乘 [T,n]×[n,m] 需要 2Tnm 次浮点运算（每个输出元素 n 次乘法 + n−1 次加法，约 2n 次）。这个公式是第 10 章算力账本的基础。

softmax：把任意实数变成概率

模型最后吐出的 17 个数（logits）可以是任意实数，有正有负。softmax 把它们压成一组和为 1 的正数：

pi​=∑j​ezj​ezi​​(2.2)

三个 logits z=[2.0, 1.0, 0.1] 手算一遍：

softmax 手算

项值
取指数e² = 7.389，e¹ = 2.718，e⁰·¹ = 1.105
求和7.389 + 2.718 + 1.105 = 11.212
相除0.659，0.242，0.099 和为 1

softmax 有两个性质：（1）加常数不变——所有 logits 同时加 5，概率一点不变，因为分子分母同时乘了 e5；（2）保序——概率的大小顺序与 logits 一致，所以取 argmax 在 softmax 前后是一回事。

交叉熵：衡量"预测得有多差"

训练时我们知道正确答案是第 t 个 token。模型给它的概率是 pt​。损失函数就是：

L=−logpt​(2.3)

如果模型给正确答案的概率是 0.9987，损失是 −log0.9987=0.0013；如果只给 0.01，损失是 4.6。概率越低，惩罚增长得越快——这正是我们想要的：模型不该"稍微猜错"，它应该对错误答案毫不留情。

对一组 N 个 token 取平均，得到平均交叉熵。它取指数就是困惑度（perplexity）：PPL=eL。困惑度是 2，意思是"模型平均在两个候选之间犹豫"；困惑度是 1.2，意思是"几乎不犹豫"。我们的小模型训练完是 1.2。

常见误解

"交叉熵是分类任务的评价指标，和生成模型没关系。"错。语言模型的训练目标就是对每个位置做一次 17 分类（或 15 万分类）的交叉熵，然后把所有位置平均。

梯度下降：唯一的学习方式

参数是随机初始化的，所以一开始预测得很差。我们要知道"把某个参数往哪个方向挪一点，能让损失变小"。这个方向就是梯度（导数）。

初中就学过的例子：f(w)=(w−3)2，最小值在 w=3。导数 f′(w)=2(w−3)。当前 w=0，导数是 −6，说明"增大 w 会让 f 减小"，所以往正方向走：

一步梯度下降（学习率 0.1）

项值
当前w = 0，f(w) = 9，f′(w) = −6
更新w ← w − η·f′(w) = 0 − 0.1×(−6) = 0.6
下一步f(0.6) = 5.76，f′(0.6) = −4.8，w ← 1.08 …

真实模型有几亿个参数，每个参数都有一条偏导数，全部拼成一个巨大的向量，就是梯度。一次更新要计算所有参数的梯度——这是反向传播干的事，第 17 章讲。

链式法则：把梯度从输出传回输入

深层网络是一串函数嵌套：x→h1​→h2​→⋯→L。想知道 ∂L/∂x，就要把每一段的导数乘起来：

∂x∂L​=∂hn​∂L​⋅∂hn−1​∂hn​​⋯∂x∂h1​​(2.4)

最重要的一个具体结果，后面会反复用到：softmax + 交叉熵的梯度，恰好是"预测减真实"：

∂zi​∂L​=pi​−yi​(2.5)

其中 y 是 one-hot 标签。推导只需要对 log 和 softmax 各求一次导再链起来，结果干净得令人愉快：预测 0.9987、真实 1.0 时，梯度是 −0.0013，几乎不用改；预测 0.05、真实 1.0 时，梯度是 −0.95，强烈要求改。这个式子就是第 19 章里 dlogits 那一行的全部内容。

三条形状规则

后面所有代码都靠这三条活命：\ ① 矩阵乘 [a,b]@[b,c] → [a,c]；\ ② 逐元素运算（加、乘、GELU、LN）不改变形状；\ ③ 对某一维求和时用 axis=…, keepdims=True，否则维度会消失，导致广播出错。第 19 章的 LayerNorm 就是靠 keepdims=True 一行写对的。
